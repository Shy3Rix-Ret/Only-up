# Flappy 3D 🐦

Flappy Bird — aber aus der **Ego-Perspektive des Vogels in 3D**! In der Lobby kann man jederzeit auf die **klassische 2D-Ansicht** umschalten.

**Spielen:** Einfach `index.html` im Browser öffnen (Handy oder Desktop). Keine Installation, keine Abhängigkeiten, läuft offline.

## Steuerung
- **Tippen / Klicken / Leertaste** = Flügelschlag
- In der Lobby: Modus wählen (3D Vogel-Perspektive oder 2D Klassisch) und START drücken

## Features
- 🐦 **3D-Ego-Perspektive**: Du siehst deine eigenen flatternden Flügel und den Schnabel, Röhren rasen mit Tiefenwirkung auf dich zu
- 🎮 **2D-Klassikmodus** mit Parallax-Hintergrund, in der Lobby umschaltbar
- 🌄 Ganz viele Hintergrund-Details: Sonne mit Glow, Wolken, zwei Bergketten, Stadt-Silhouette (abends leuchten die Fenster!), Windmühlen mit drehenden Flügeln, Heissluftballons, Vogelschwärme, Häuser mit Kaminrauch, Bäume, Büsche mit Beeren, Blumen, Felsen, Gras, Schmetterlinge
- 🌅 Sanfter Tag-/Abend-Farbwechsel je weiter du fliegst
- 🔊 Sound-Effekte (abschaltbar), Vibration beim Aufprall
- 🏆 Rekord wird gespeichert, Medaillen beim Game Over
- 📱 Für Handys optimiert: reines Canvas-2D-Rendering, ~60 FPS, begrenzte Pixeldichte, Objekt-Recycling — kein Lag

# VoxScribe 🎙️ – Transkription DE / EN / gemischt

Sprich – alles wird live und sehr genau transkribiert. Einfach `transkript.html` im Browser öffnen
(**Chrome, Edge oder Safari**; die Spracherkennung braucht eine Internetverbindung). Keine Installation,
keine Abhängigkeiten, alle Daten bleiben lokal im Browser.

## Sprachen
- 🇩🇪 **Deutsch** und 🇬🇧 **English** – jeweils mit voller Genauigkeit
- 🔀 **Gemischt DE+EN**: zwei Erkenner laufen parallel, pro Satz gewinnt das Ergebnis mit der höheren
  Erkennungssicherheit. So kannst du Deutsch sprechen und trotzdem englische Wörter einstreuen.
  Über den Regler „Bevorzugte Sprache im Zweifel“ lässt sich die Gewichtung einstellen.
- In den Einstellungen sind weitere Sprachen wählbar (AT/CH, UK/US/AU, FR, ES, IT, TR, NL, PL, PT) –
  auch als beliebiges gemischtes Paar.

## Features
- ✍️ **Live-Transkript** mit Zwischenergebnissen, Zeitstempeln und Sprach-Label pro Abschnitt
- 🎯 **Auto-Interpunktion**: Groß-/Kleinschreibung und Satzzeichen werden automatisch gesetzt
- 🗣️ **Sprachbefehle**: „Punkt“, „Komma“, „Fragezeichen“, „neue Zeile“, „neuer Absatz“ –
  genauso auf Englisch („period“, „comma“, „new line“, „new paragraph“ …)
- 📖 **Eigenes Wörterbuch**: Ersetzungen wie `kubernetis = Kubernetes` korrigieren Namen und
  Fachbegriffe automatisch – das bringt bei Fachsprache die größte Genauigkeit
- 🚫 **Füllwörter** (äh, ähm, quasi, uh, um, like …) hervorheben oder direkt entfernen
- ⚠️ **Unsichere Stellen** werden gepunktet unterstrichen – so siehst du sofort, wo du prüfen musst
- 📝 **Direkt editierbar**: Antippen und korrigieren, Zeitstempel bleiben erhalten
- 📊 **Statistik**: Wörter, Zeichen, Sätze, Sprechtempo (WPM), Ø Satzlänge, Füllwortquote,
  Lesezeit, Sprachverteilung
- 📈 **Live-Wellenform** mit Pegelanzeige und Warnung, wenn es zu leise ist
- 🔊 **Audio-Mitschnitt** parallel zur Transkription (als `.webm` herunterladbar)
- ⬇️ **Export**: Zwischenablage, TXT, Markdown (mit Zeitstempeln) und **SRT-Untertitel**
- 🔈 **Vorlesen** des Transkripts per Sprachausgabe
- 💾 **Sitzungsarchiv**: Transkripte benennen, speichern, wieder laden; Autosave übersteht Neuladen
- 🔍 **Volltextsuche** im Transkript mit Treffer-Hervorhebung
- ♾️ **Dauerbetrieb**: startet nach Sprechpausen automatisch neu – für lange Diktate
- 💡 **Bildschirm wachhalten**, 🌙 Dark/Light-Design, große Schrift, mobil optimiert
- ⌨️ **Kürzel**: `Strg/Cmd + M` Aufnahme starten/stoppen, `Strg/Cmd + F` Suche, `Esc` stoppen
